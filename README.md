## About the Repository

This repository contains solutions to LeetCode problems submitted through the LeetPush extension. Each solution folder is named using the LeetCode problem number and title, making it easy to search for a problem or study a specific topic.

A typical problem folder includes:

- the problem statement and constraints in `README.md`;
- a source-code implementation; and
- direct links to the corresponding LeetCode problem when available.

## Repository Structure

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/priyansh019/Leetcode-Solutions.git
cd Leetcode-Solutions
```

### Compile a C++ Solution

```bash
g++ -std=c++17 -O2 "1-two-sum/1-Two-Sum.cpp" -o solution
./solution
```

Replace the paths above with the `.cpp` file you want to compile.

### Add a Solution

1. Create a folder named in LeetCode format: `<problem-number>-<problem-title>`.
2. Add the problem's `README.md`.
3. Add the solution source file.
4. Include comments for important logic and edge cases.
5. Commit and push the changes.
